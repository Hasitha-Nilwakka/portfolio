# Hasitha Nilwakka — Portfolio Website

A modern, high-conversion engineering portfolio built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**.

## Features
- **Executive Hero Section:** Immediate clarity on your hybrid strengths (10+ years banking/operations + modern Full-Stack & Systems engineering), Espoo location, and immediate Finnish work authorization.
- **The "Unfair Advantage" Pillars:** Clear 3-way breakdown (Full-Stack & GenAI, Cloud & GitOps, FinTech & MBA Leadership).
- **Interactive Project Showcase:** Filterable by category (All, AI & Full-Stack, Cloud & DevOps, Systems), featuring direct live demo link to [Resume Radar](https://resume-radar-hvb3ka7hq-hasitha-nilwakkas-projects.vercel.app/) on Vercel and GitHub repositories.
- **Dark / Light Theme Toggle:** Clean color switching with CSS variables and glassmorphism.
- **Lightweight & Fast:** Static generation with sub-115kB initial bundle size.

## Quick Start (Run Locally)

```bash
# 1. Install dependencies
pnpm install

# 2. Run local development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
pnpm build
pnpm start
```

## Deploying to Vercel (1-Click Deployment)

1. Push this directory to your GitHub account (`github.com/Hasitha-Nilwakka/portfolio`).
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import the `portfolio` repository.
4. Click **Deploy**. Vercel will automatically detect Next.js and deploy it globally within 30 seconds!
